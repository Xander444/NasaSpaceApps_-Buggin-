# AI-use acknowledgment

GitHub Copilot assisted with code authoring and review during submission preparation. The optional SI-guided evidence-search feature uses Google Gemini (`gemini-3.5-flash-lite`) only after a user explicitly selects **Analyze**. It receives the user's query and bounded context, then ranks eligible study records and exact source excerpts.

The local keyword search, required-condition matching, citation checks, and export eligibility remain deterministic. SI output is not a scientific finding, measurement, fire prediction, or safety recommendation. The team is responsible for reviewing the cited NASA source records and the final submission.
