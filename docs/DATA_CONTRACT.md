# Data team contract

The data pipeline must preserve source facts separately from parsed or modeled values.

## Required principles

- One normalized row represents one test or burn, not an entire investigation.
- Every row must have an investigation accession, test/sample identifier, source file, and source row/page/timestamp.
- Preserve the original cell as `*_raw` whenever parsing is lossy or ambiguous.
- Use `null` for missing values. Never use zero as a missing-data placeholder.
- Store units in the field name or a companion unit field.
- Record whether a value is reported, parsed, calculated, interpolated, or modeled.
- Do not convert fan display values into flow speed without a documented calibration source.
- Keep ingestion reproducible: source filename, source version, byte count, and SHA-256.

## Current outputs

- `data/psi/catalog.json`: investigation summaries from the public NASA PSI API.
- `data/psi/file_inventory.json`: public file names, categories, sizes, and versions.
- `data/psi/tables/`: downloaded public experimental tables.
- `data/psi/normalized/bass_ii_tests.json`: normalized BASS-II rows.
- `data/psi/manifest.json`: import time, hashes, counts, and failures.
- `data/source_review.json`: reproducible NASA/CSA search scope, inclusion decisions, and explicit exclusions.

The November 2026 catalog contains 24 selected NASA PSI investigations, 16,354 indexed public files, 22 downloaded experimental tables, and 2,870 raw table rows (including 861 empty rows). The search review found no CSA dataset eligible for the spacecraft-fire ranking; the atmospheric MOPITT match is documented but excluded.

## Pull request checklist

- [ ] New source is an official NASA or peer-reviewed primary source.
- [ ] Source accession/DOI is recorded.
- [ ] Units are explicit.
- [ ] Missing values remain null.
- [ ] Ambiguous values preserve raw text.
- [ ] At least five representative rows were manually checked.
- [ ] No model coefficient is presented as a measured NASA value.

## Search contract v1 (additive)

`public/search/index.json` is generated by `analysis/build_search_index.py`, independently of import/build commands. Its `schema_version: 1` covers `investigations`, typed `documents`, `sources`, `facets`, `diagnostics`, input hashes, and content-based `index_version`. A document is an investigation, test, passage, or file; file metadata is never described as indexed full text. Condition values contain value/unit/raw/method/source IDs. All existing source JSON and simulator schemas remain unchanged. See [SEARCH.md](SEARCH.md) for normalization coverage, the BASS-II oxygen discrepancy, unknown measured gravity, source-review examples, and an explicitly illustrative record shape.

`data/search/config.json` versions aliases/rules/annotations. `legacy_annotations.json` archives unverified prototype copy outside the canonical scientific index. The semantic service shares stable document IDs and must return the exact index version. Export schema v1 includes only selected currently verified test rows and their cited comparison evidence.
